レッスン予定の管理・更新

設定と更新はGitHubにログインして操作します。このページは操作先の案内です。

1. APIキーを登録する

管理者がGitHubの「New repository secret」で登録します。

Name
HACK_RESERVATION_API_TOKEN
Secret
発行済みのAPIキー本体（Bearerは付けません）
GitHubでAPIキーを設定 ↗

2. 対象教室を設定する

「New repository variable」で、次の2項目を登録します。

LESSON_CLASSROOM_IDS
対象の教室IDをカンマ区切りで入力。管理者が予約システムの教室IDと照合してください。
LESSON_API_ENABLED
取得した日時・教室名・コース名を一般公開してよいことを確認後、trueを設定します。未設定・falseでは準備中表示になります。
GitHubで教室・表示を設定 ↗

3. 予定を取得・公開する

「Run workflow」でブランチmainを選び、実行します。取得と公開が緑のチェックで完了したら、表示ページを確認してください。

叩き台の運用

  • 対象は当月・翌月。下書きを除き、開催中と次の開始時刻のレッスンを表示します。
  • 現在は手動更新とmainへのpush時に取得します。自動の定期取得はまだ設定していません。
  • 予定の有効期限は取得から24時間です。教室で使う前に更新してください。
  • 取得に失敗した場合、公開ページは更新されません。前回の予定も期限を過ぎると非表示になります。
  • 担当講師はAPIの項目が未確認のため、まだ表示しません。
  • スタッフの更新操作には、このリポジトリへの書き込み権限が必要です。APIキーの設定は管理者が行います。
